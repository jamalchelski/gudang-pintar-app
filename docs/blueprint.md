# **App Name**: Gudang Pintar

## Core Features:

- Inventory Display: Inventory list with item name, brand, unit, category, quantity, min, and max values.
- User Roles: Role-based access: Admin (full access), User (search and reduce stock).
- Data Import/Export: Import/Export inventory data using XLS, CSV, XLSX files.
- Automatic Reorder Calculation: Calculate and export a list of items that need restocking based on quantity.
- Stock Reduction Interface: Interface to reduce inventory quantities as items are taken from warehouse stock.

## Style Guidelines:

- Primary color: Deep navy (#1E3A8A) for a professional look, referencing the user's request.
- Background color: Very light grayish blue (#F0F4F8).
- Accent color: Amber (#F59E0B) for warnings and important actions, as requested.
- Body and headline font: 'Inter', a grotesque sans-serif known for its modern, objective, and neutral look.
- Mobile-first responsive design optimized for tablets and phones.
- Navigation sidebar with menu items tailored to user roles.
